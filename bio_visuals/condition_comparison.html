How these comparisons were calculated

Each animal contributes one section-level value per PLA arm. Group means give every animal the same weight, regardless of the number of detected objects. All differences use Home cage − Running; positive values mean higher values in the non-running group. The animals in the two groups are not paired.

Delete-one-per-group ranges use all nine ways to omit one animal from each group. They assess sensitivity to individual animals; they do not estimate population uncertainty. Counts reflect sampled tissue and detection settings, and cannot be interpreted as tissue density without valid area measurements.

Size standardization uses only strata meeting the minimum count in every animal. A common reference size distribution is calculated from equal-animal size shares and applied to every animal. Delete-one sensitivity checks hold the full-cohort eligibility and common weights fixed. It is a descriptive composition check; it cannot establish mechanism, causation, molecular binding or enzyme activity.
