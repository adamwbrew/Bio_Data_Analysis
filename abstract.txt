file is organized as an object-by-feature table. Each row represents one individual object detected by HALO, such as a PLA punctum or other segmented object within the analyzed image. The columns describe the properties of that object. The columns generally include an object identifier, the object's spatial position within the image (for example X and Y coordinates), morphological measurements such as object area, and signal measurements associated with the fluorescence channels used in that analysis. Additional columns contain the HALO classification or colocalization results for the relevant markers, indicating whether each individual PLA object is spatially associated with a marker
